# لوحة تحكم إدارة المطعم / الكافيه

أداة ويب لإدارة بيانات مطعمك في مكان واحد وتحليلها زي مدير أعمال: بتسجّل المبيعات
والمصروفات والعروض والقرارات الإدارية، والأداة بترجع لك تلقائيًا تحليل لكل قرار
وعرض (تأثيره على المبيعات قبل وبعد) وتوصيات عملية.

## المميزات

- **المبيعات اليومية**: تسجيل الإيرادات وعدد الطلبات يوميًا.
- **المصروفات**: تسجيل المصروفات مبوبة (مستلزمات، رواتب، إيجار، مرافق، تسويق، أخرى).
- **العروض**: تسجيل كل عرض بتاريخ بدايته ونهايته، والأداة بتحسب تلقائيًا متوسط
  المبيعات قبل العرض وأثناءه ونسبة التغيير، وتديله تقييم (ناجح / تأثير محدود / أثر سلبي).
- **القرارات الإدارية**: تسجيل كل قرار (تسعير، تشغيل، عمالة...) مع السبب والنتيجة
  المتوقعة، والأداة بتقارن المبيعات قبل وبعد القرار وتديله تقييم.
- **لوحة القيادة**: إجمالي الإيرادات والمصروفات وصافي الربح وهامش الربح، رسم بياني
  لاتجاه المبيعات، وتوزيع المصروفات حسب البند.
- **تقرير مدير الأعمال**: توصيات تلقائية مبنية على البيانات الفعلية (هامش ربح
  منخفض، بند مصروف مرتفع عن الطبيعي، عرض ناجح يستحق التكرار، قرار بنتيجة سلبية...).

## التشغيل

```bash
npm install
npm start
```

بعدها افتح المتصفح على `http://localhost:3000`.

يمكنك الضغط على "تحميل بيانات تجريبية" من أعلى الصفحة عشان تجرب الأداة ببيانات
جاهزة، أو "تصفير البيانات" لمسح كل حاجة والبدء من الصفر.

## آلية التقييم

- **العروض**: بيتحسب متوسط الإيرادات اليومية لمدة 14 يوم قبل بداية العرض
  (Baseline)، ويتقارن بمتوسط الإيرادات أثناء فترة العرض. زيادة 10%+ = "ناجح"،
  من -5% إلى 10% = "تأثير محدود"، أقل من -5% = "أثر سلبي".
- **القرارات**: نفس المبدأ، بمقارنة متوسط المبيعات 14 يوم قبل تاريخ القرار
  بمتوسط المبيعات بعده (أو لحد النهاردة لو لسه مضاش 14 يوم). القرارات الأحدث
  من 3 أيام بتتحط "قيد التقييم" لحد ما يبقى فيه بيانات كافية.
- هذا تحليل إحصائي مبني على بياناتك (Rule-based)، مش تنبؤ سحري — قيمته بتزيد
  كل ما تسجّل بيانات مبيعات بانتظام (يوميًا لو أمكن).

## البنية التقنية

- **الخادم**: Node.js + Express (`server.js`)، بدون قاعدة بيانات خارجية —
  البيانات بتتخزن في ملف `data/store.json` (بيتولد أوتوماتيك، ومش متتبع في Git).
- **محرك التحليلات**: `lib/insights.js` — بيحسب كل المقاييس والتوصيات.
- **الواجهة**: صفحة واحدة (`public/index.html` + `public/app.js` + `public/style.css`)
  من غير أي مكتبات خارجية أو اتصال إنترنت مطلوب.

## نسخ احتياطي للبيانات

كل بياناتك محفوظة في `data/store.json`. تقدر تعمل نسخة احتياطية بنسخ الملف ده،
أو تستورده تاني بنفس الاسم في نفس المكان.
