# نظام إدارة التوزيع

برنامج ويب متكامل لإدارة شركة توزيع منتجات: مخزون، تصنيع، موردين، عملاء،
سيارات ورحلات توزيع، فواتير، ودورة محاسبية كاملة بالقيد المزدوج.

## الفكرة

النظام مبني حوالين طبيعة عمل شركة توزيع فيها:

- **مخزن** بيتوزع منه بضاعة أحيانًا **زي ما هي** (بضاعة جاهزة اتشترت من مورد
  وبتتباع كما هي) وأحيانًا بعد **تصنيع/تجهيز** (مواد خام بتتحول لمنتج نهائي
  بتركيبة (BOM) محددة).
- **موردين متعددين** بيتم الشراء منهم بفواتير شراء، وكل مورد له كشف حساب.
- **عملاء** بيتوزع عليهم المنتج ببيع آجل أو نقدي، وكل عميل له كشف حساب وحد ائتمان.
- **سيارات** خاصة أو مأجورة بتنقل البضاعة من المخزن للعميل في شكل **رحلات
  توزيع**: بيتحمّل عليها بضاعة، وبيتباع منها للعملاء أثناء الرحلة، وأي بضاعة
  ما اتباعتش بترجع للمخزن (مرتجع)، وأي بضاعة اتكسرت/اتلفت بتتسجل **توالف**.
  في نهاية الرحلة بتتعمل **تسوية** بتقارن المحمّل بالمباع والمرتجع والتالف
  عشان تكتشف أي عجز.
- **مصروفات عامة** (إيجار، رواتب، مرافق...) ومصروفات خاصة بكل رحلة (وقود،
  صيانة، رسوم طريق...).
- **سندات قبض وصرف** لتحصيل مديونيات العملاء وسداد مديونيات الموردين
  ولأي حركة نقدية أخرى (رأس مال، مسحوبات شخصية...).

كل عملية من العمليات دي بترحّل **تلقائيًا** قيد محاسبي بالقيد المزدوج (مدين =
دائن) على شجرة حسابات جاهزة، فيبقى عندك في أي وقت: ميزان مراجعة، قائمة دخل
(أرباح وخسائر)، ومركز مالي مبسط (ميزانية) - كل ده مبني من نفس بيانات التشغيل
اليومية بدون أي إدخال يدوي إضافي.

## التشغيل

يحتاج **Node.js 22.5 أو أحدث** (بيستخدم دعم SQLite المدمج في Node، فمفيش أي
قاعدة بيانات خارجية لازم تتركب).

```bash
cd distribution
npm install
npm start
```

بعدها افتح المتصفح على `http://localhost:3001`.

البيانات بتتخزن في ملف `data/app.db` (بيتولد أوتوماتيك، ومش متتبع في Git).
لعمل نسخة احتياطية، انسخ الملف ده. لتصفير النظام بالكامل، امسح الملف ده
وأعد تشغيل السيرفر.

## جولة سريعة في الاستخدام

1. **المنتجات**: ضيف منتجاتك وحدد نوع كل واحد:
   - *بضاعة جاهزة*: بتتباع زي ما اتشترت.
   - *مادة خام*: بتدخل كمكوّن في تصنيع منتج تاني.
   - *منتج مُصنّع*: ناتج من تصنيع مواد خام - تقدر تحدد تركيبته (BOM) من صفحة
     تفاصيل المنتج.
2. **الموردين**: ضيف الموردين اللي بتشتري منهم.
3. **فواتير الشراء**: سجّل كل عملية شراء (بيزوّد المخزون ويحسب متوسط تكلفة
   الوحدة تلقائيًا، ويسجّل المديونية على المورد لو الفاتورة آجلة).
4. **أوامر التصنيع**: لو عندك منتج مُصنّع، اعمل أمر تصنيع بيستهلك المواد
   الخام حسب التركيبة (أو تحدد الكميات يدويًا) وينتج المنتج النهائي بتكلفة
   محسوبة تلقائيًا.
5. **السيارات**: ضيف سياراتك (ملك أو مأجورة).
6. **رحلات التوزيع**: افتح رحلة، حمّل عليها بضاعة، سجّل فواتير البيع للعملاء
   أثناء الرحلة، سجّل مصروفات الرحلة (وقود...)، وفي الآخر سجّل المرتجع وسوّي
   الرحلة - النظام بيوريك أي فرق (عجز) بين المحمّل والمباع والمرتجع.
7. **التوالف**: سجّل أي بضاعة اتلفت (سواء بالمخزن أو أثناء رحلة).
8. **المصروفات والسندات**: سجّل المصروفات العامة وسندات القبض من العملاء
   والصرف للموردين.
9. **الحسابات والتقارير**: من صفحة "الحسابات والتقارير" تقدر تشوف شجرة
   الحسابات، دفتر اليومية، ميزان المراجعة، قائمة الدخل، والمركز المالي -
   كلها بتتحدث لحظيًا مع كل عملية.

## البنية التقنية

- **الخادم**: Node.js + Express (`server.js`).
- **قاعدة البيانات**: SQLite عن طريق وحدة `node:sqlite` المدمجة في Node
  (بدون أي تركيب إضافي) - الملف في `lib/db.js` والهيكل في `lib/schema.sql`.
- **المحرك المحاسبي**: `lib/accounting.js` (ترحيل القيود بالقيد المزدوج)
  و`lib/accounts.js` (شجرة الحسابات الافتراضية وربط كل عملية بحساباتها).
- **منطق التشغيل**: `lib/services.js` (كل عملية تجارية: شراء، بيع، تصنيع،
  تحميل/تفريغ رحلة، توالف، مصروفات، سندات) و`lib/inventory.js` (حساب متوسط
  التكلفة المرجح للمخزون) و`lib/reports.js` (كشوف الحسابات والتقارير المالية).
  كل عملية بتتنفذ جوه معاملة (transaction) واحدة: لو حصل خطأ في أي جزء
  (زي عدم كفاية المخزون) بيتم التراجع الكامل ومفيش بيانات ناقصة.
- **الواجهة**: صفحة واحدة (SPA) بجافاسكريبت عادي بدون أي مكتبات خارجية -
  `public/index.html` + `public/style.css` + ملفات `public/js/`.
