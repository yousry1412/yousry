# نشر "أفواج" أونلاين (زي برنامج إدارة التوزيع بالظبط)

نفس طريقة برنامج التوزيع: Node.js + قاعدة بيانات SQLite على **قرص دائم** في Render، والصور والمرفقات محفوظة على نفس القرص.

## أول مرة (حوالي 10 دقايق)
1. ادخل [dashboard.render.com](https://dashboard.render.com) وافتح الـ **Blueprint** بتاع `distribution-erp`.
2. لو المزامنة التلقائية شغالة، الخدمة **umrah-erp** هتظهر وتتنشر لوحدها. لو لأ: **Manual Sync** ← **Apply**.
3. بعد 3–5 دقايق هتلاقي رابط زي `https://umrah-erp-xxxx.onrender.com`.
4. افتح الرابط **فوراً** واعمل حساب المالك قبل ما تشارك الرابط (أول حساب = المالك).
5. **الإدارة ← الشركة والفروع والضرائب**: غيّر اسم الشركة وبياناتها والدولة ونسبة الضريبة.
6. **الإدارة ← النسخ الاحتياطي**: لو عاوز تبدأ ببياناتك الحقيقية اضغط **مسح البيانات والبدء من جديد** (بتتحفظ نسخة من التجريبي تقدر ترجعلها).
7. **الإدارة ← المستخدمون والصلاحيات**: أضف حساب لكل موظف، ولكل مندوب (واربطه بسجله من "الوكلاء والمناديب")، ولكل مشرف ومندوب تسكين.

## لو كنت نشرت النسخة السابقة
مفيش حاجة تعملها — أول تشغيل بيحوّل قاعدة البيانات القديمة تلقائياً (المستخدمين والبيانات) للنظام الجديد بالحسابات والشركات. اتجربت الترقية دي فعلياً قبل الرفع.

## ترتيب إدخال البيانات الحقيقية
الموردون ← الفنادق والمخصصات ← الرحلات (رحلة جديدة + الغرف) ← التكلفة والتسعير (قفل السعر) ← الوكلاء والمناديب ← الخزائن والبنوك ← الحجوزات.

## الحماية والنسخ الاحتياطي
- كلمات السر مشفرة (scrypt)، قفل بعد 5 محاولات خاطئة لمدة 15 دقيقة، جلسات آمنة (HttpOnly/Secure/SameSite)، حماية CSRF، سياسة أمان محتوى (CSP).
- **الصلاحيات مفروضة على السيرفر**: القيد المرحّل والسند المعتمد لا يُعدلان ولا يُحذفان، الاعتماد للمحاسب/المدير فقط، زيادة محفظة وكيل أو تعديل مسدد حجز بسند معتمد فقط، والمندوب والمشرف لا يستلموا غير بياناتهم.
- **كل حفظ** يحتفظ بالنسخة السابقة (آخر 60 + نقاط الحفظ المسماة) ويمكن استرجاع أي نسخة.
- **نسخة يومية تلقائية** كاملة على القرص (آخر 14 يوم).
- **نسخة على فلاشة**: الإدارة ← النسخ الاحتياطي ← "تنزيل النسخة الكاملة" (كل الشركات والمستخدمين والصور) — واسترجاعها من نفس الصفحة على أي سيرفر.

## التكلفة
خدمة Starter ≈ **7 دولار شهرياً** + أقل من دولار للقرص — نفس برنامج التوزيع.

## التشغيل على جهازك
```bash
cd umrah-erp
npm install
npm start          # http://localhost:3002
```
