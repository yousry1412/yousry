# نشر Smart Umrah ERP أونلاين (زي برنامج إدارة التوزيع بالظبط)

البرنامج دلوقتي بيشتغل على سيرفر حقيقي:
- **كل موظف بيدخل بحسابه** (اسم مستخدم وكلمة سر)، وصلاحية الخصم والاعتماد مربوطة بدوره.
- **البيانات مشتركة** بين الكل ومحفوظة على السيرفر، وأي تعديل بيظهر عند الباقيين خلال ثوانٍ.
- لو اتنين عدّلوا في نفس اللحظة، البرنامج **مبيمسحش شغل حد** — التاني بيجيله تنبيه يعيد العملية على آخر نسخة.
- الحجوزات المعلقة بتتحرر تلقائياً في ميعادها حتى لو محدش فاتح البرنامج.

## الخطوات على Render (نفس حساب برنامج التوزيع)

الإعدادات موجودة بالفعل في ملف `render.yaml` كخدمة تانية اسمها **umrah-erp**.

1. ادخل [dashboard.render.com](https://dashboard.render.com) وافتح الـ **Blueprint** اللي فيه `distribution-erp`.
2. لو المزامنة التلقائية (Auto Sync) شغالة، Render هيلاقي الخدمة الجديدة لوحده بعد آخر تحديث للفرع ويبدأ ينشرها.
   لو مش شغالة: دوس **Manual Sync** ← هيعرض لك الخدمة الجديدة **umrah-erp** + قرص 1GB ← **Apply**.
   (لو الـ Blueprint مش موجود أصلاً: **New +** ← **Blueprint** ← اختار الريبو `yousry1412/yousry` والفرع `claude/lucid-babbage-4nbzzr`.)
3. استنى 3–5 دقايق لحد ما البناء يخلص. هتلاقي رابط زي:
   `https://umrah-erp-xxxx.onrender.com`
4. افتح الرابط **فوراً** واعمل حساب المالك (أول حساب بيتعمل هو المالك). مهم تعمله بنفسك قبل ما تشارك الرابط.
5. من القائمة: **الإدارة ← المستخدمون والصلاحيات** ← أضف حساب لكل موظف بدوره:

| الدور | يقدر يعمل |
|---|---|
| المالك | كل حاجة + إدارة المستخدمين + إعادة البيانات التجريبية |
| مدير مبيعات | خصم حتى 7% · اعتماد الخصومات · التسعير الإداري · قفل الأسعار والتسكين |
| رئيس قسم | خصم حتى 3% |
| موظف مبيعات | بدون خصم — أي خصم بيروح للاعتماد |
| عمليات وتسكين | التسكين والباص والجوازات والتقارير |

6. ابعت لكل موظف الرابط + اسم المستخدم وكلمة السر بتاعته.

## التكلفة
خدمة جديدة بخطة **Starter** ≈ **7 دولار شهرياً** + أقل من دولار للقرص — نفس برنامج التوزيع.
القرص الدائم ضروري عشان البيانات متتمسحش مع كل إعادة تشغيل.

## ملاحظات مهمة
- البرنامج بيبدأ ببيانات **تجريبية** (رحلة وحجوزات وهمية) عشان تجربوه. المالك يقدر يعيدها من زرار **↺ بيانات تجريبية**.
  النسخة الحالية مبنية حول **رحلة واحدة**؛ إضافة رحلات متعددة وإدخال بياناتكم الحقيقية من الصفر هي الخطوة الجاية.
- النسخ الاحتياطي: من Render ← الخدمة ← **Disks** ← Snapshots (Render بيعمل نسخة يومية تلقائياً).
- فتح `public/index.html` مباشرة من غير سيرفر لسه شغال كنسخة عرض لمستخدم واحد (البيانات في المتصفح بس).

## التشغيل على جهازك
```bash
cd umrah-erp
npm install
npm start          # http://localhost:3002
```
