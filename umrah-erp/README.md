# Smart Umrah ERP 🕋

منظومة تكوين رحلات العمرة، التكاليف متعددة العملات، بنك الغرف، حوكمة المبيعات، والتسكين التفاعلي بنظام مقاعد الحافلات.

## التشغيل
- **أونلاين لفريق كامل:** انظر [`DEPLOY.md`](DEPLOY.md) — خدمة `umrah-erp` على Render بحسابات دخول وبيانات مشتركة.
- **على جهازك:** `cd umrah-erp && npm install && npm start` ثم `http://localhost:3002` (أول مرة تعمل حساب المالك).
- **عرض سريع بدون سيرفر:** افتح `public/index.html` مباشرة — نسخة لمستخدم واحد، البيانات في المتصفح، وتقدر تبدّل **المستخدم الحالي** من الشريط العلوي لتجربة الصلاحيات.
- البيانات التجريبية تُحمّل تلقائياً وتواريخها نسبية لليوم الحالي.

## جولة تجربة مقترحة (5 دقائق)
1. **محرك الحجز** ← ✨ تعبئة تجريبية ← حفظ ← تنتقل تلقائياً لخريطة الأسرّة مع حجب غرف الجنس الآخر ← اضغط السرير الأخضر النابض.
2. **التسكين المزدوج** ← وضع Swap ← اضغط سرير رجل ثم سرير سيدة ← يُرفض التبديل (منع الاختلاط).
3. **دفتر الحجوزات** ← ⏩ على حجز معلق ← بعد 5 ثوانٍ يتحرر السرير تلقائياً.
4. **رادار الإتاحات** ← اختر يومين ← ذروة ×1.2 ← حجز سريع للوكيل من المحفظة.
5. **التسكين** ← 🔢 تحويل الأكواد لأرقام فعلية ← 🔒 قفل التسكين ← **العمليات** ← كشف التسكين السعودي ← Excel/PDF.
6. **بوابة الوكلاء** ← دخول وكيل متأخر السداد (PIN `1903`) ← الحجز الذاتي مقفل.

## الاختبارات
```bash
cd umrah-erp && npm test                                              # 20 اختبار للمحرك
psql -d umrah -v ON_ERROR_STOP=1 -f umrah-erp/db/schema.sql
psql -d umrah -v ON_ERROR_STOP=1 -f umrah-erp/db/tests.sql          # 63 فحصاً لثوابت قاعدة البيانات
```

## الملفات
| الملف | المحتوى |
|---|---|
| `ARCHITECTURE.md` | المرجع المعماري: السياقات، تدفق البيانات، آلات الحالة، الخوارزميات، مصفوفة الثوابت، خارطة الإنتاج |
| `db/schema.sql` | PostgreSQL DDL: Enums، القيود، المفاتيح، دوال PL/pgSQL والمحفزات، الـ Views |
| `db/tests.sql` | اختبارات الثوابت (منع الاختلاط، الغرف المغلقة، السقف الائتماني، TTL، الاعتمادات…) |
| `server.js`, `lib/store.js` | السيرفر: حسابات الدخول، الحالة المشتركة بإصدارات (منع الكتابة فوق شغل غيرك)، تحرير الحجوزات المنتهية تلقائياً |
| `public/js/engine.js` | محرك قواعد العمل النقي (قابل للاختبار في Node) |
| `public/js/data.js` | البيانات التجريبية |
| `public/js/core.js` | المخزن، الحفظ، تفويض الأحداث، الطباعة والتصدير، مؤقت التعليق |
| `public/js/pages-sales.js` | البناء والتكلفة، الرادار، الحجز، الوكلاء |
| `public/js/pages-ops.js` | التسكين المزدوج، الباص، العمليات والتقارير، الأرباح |
| `public/js/pages-admin.js` | المستخدمون والصلاحيات (المالك) |

> النسخة الأونلاين تحفظ الحالة كمستند واحد بإصدارات في SQLite على السيرفر. نموذج PostgreSQL الكامل في `db/` هو هدف الإنتاج التالي — انظر §9 في `ARCHITECTURE.md`.
