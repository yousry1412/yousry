# أفواج — منظومة شركات العمرة 🕋

منظومة شركات العمرة: الرحلات، التكاليف متعددة العملات، بنك الغرف، الحجوزات، التسكين التفاعلي بنظام مقاعد الحافلات، والحسابات الكاملة بالقيد المزدوج — لعدة شركات وفروع، مع بوابات للمناديب والمشرفين.

## التشغيل
- **أونلاين لفريق كامل:** انظر [`DEPLOY.md`](DEPLOY.md) — خدمة `umrah-erp` على Render (نفس طريقة برنامج التوزيع: SQLite على قرص دائم).
- **على جهازك:** `cd umrah-erp && npm install && npm start` ثم `http://localhost:3002` (أول مرة تعمل حساب المالك).
- **عرض سريع بدون سيرفر:** افتح `public/index.html` مباشرة — نسخة عرض لمستخدم واحد (بدون رفع ملفات أو شات).

## الأقسام (القائمة الجانبية)
| المجموعة | الشاشات |
|---|---|
| 🏠 الرئيسية | لوحة التحكم · مركز التنبيهات (تحصيل، أقساط متأخرة، جوازات، مستندات ناقصة، سندات بانتظار الاعتماد) · الإشعارات · سعر الصرف العالمي |
| ✈️ الرحلات والتشغيل | الرحلات (متعددة، كل رحلة مركز تكلفة) · التكلفة والتسعير · رادار الإتاحات · التسكين المزدوج · مقاعد الباص · العمليات والكشوف (جوازات، برنامج، واتساب، كشف التسكين السعودي، مانيفست، فوتشر، **كشف المشرف**، **كشف مندوب التسكين**) · ملفات الرحلة (تذاكر، تأشيرات، باركود) |
| 🧾 المبيعات والعملاء | الحجوزات (صورة شخصية + صورة جواز لكل مسافر، صفحة تفاصيل كاملة لكل حجز) · العملاء (تكويد + كشف حساب) · الوكلاء والمناديب |
| 🏨 الموردون والفنادق | الموردون (تكويد، فواتير، سداد بفروق العملة) · الفنادق والمخصصات (تكويد) |
| 💰 المالية والحسابات | الخزائن والبنوك · السندات والاعتمادات (الدورة المستندية) · المصروفات (بنود) · الموظفون (سلف/عهد/رواتب) · شجرة الحسابات · القيود اليومية · التقارير المالية (ميزان مراجعة، أستاذ، دخل، مركز مالي، أرصدة الأطراف) · أرباح الرحلة |
| 💬 التواصل | شات داخلي بالصور والكاميرا والمرفقات |
| ⚙️ الإدارة | الشركة والفروع والضرائب · المستخدمون والصلاحيات · النسخ الاحتياطي والإصدارات والمسح |

## الأدوار
المالك · مدير · محاسب · رئيس قسم مبيعات · موظف مبيعات · عمليات وتسكين — وبوابات منفصلة لـ: **المندوب/الوكيل** (حسابه، حجوزاته، رفع دفعات بالصور) · **المشرف** · **مندوب التسكين**.

## الاختبارات
```bash
cd umrah-erp
npm test                 # 32 اختبار: المحرك + الحسابات + الحوكمة
npm start & npm run test:e2e   # 15 اختبار أونلاين على سيرفر بقاعدة بيانات جديدة (DATA_DIR فارغ)
psql -d umrah -v ON_ERROR_STOP=1 -f db/schema.sql && psql -d umrah -f db/tests.sql   # 63 فحص PostgreSQL
```

## الملفات

|---|---|
