# أفواج — منظومة شركات العمرة 🕋

منظومة شركات السياحة: **العمرة** و**السياحة الداخلية** (كل شركة/فرع يختار مجاله) — الرحلات والبرامج، التكاليف متعددة العملات، الحجوزات والتسكين، الحسابات الكاملة بالقيد المزدوج والضرائب حسب الدولة، الموارد البشرية وقياس الأداء، واتساب بيزنس — لعدة شركات وفروع، مع بوابات للمناديب والمشرفين.

## التشغيل
- **أونلاين لفريق كامل:** انظر [`DEPLOY.md`](DEPLOY.md) — خدمة `umrah-erp` على Render (نفس طريقة برنامج التوزيع: SQLite على قرص دائم).
- **على جهازك:** `cd umrah-erp && npm install && npm start` ثم `http://localhost:3002` (أول مرة تعمل حساب المالك).
- **عرض سريع بدون سيرفر:** افتح `public/index.html` مباشرة — نسخة عرض لمستخدم واحد (بدون رفع ملفات أو شات).

## قواعد مهمة
- **الخصم على أي سعر من صلاحية مالك النظام فقط** — أي خصم من غيره يُرفع للمالك للاعتماد (مفروض على السيرفر).
- **عمولة المندوب**: رقم مقطوع لكل فرد أو لكل حجز مع حد أدنى في تكويده، وسعر عمولة لكل رحلة/برنامج لا يقل عن الحد الأدنى، والمالك وحده يضيف أو يخصم على عمولة أي حجز بسبب مسجل. تُرحّل على 5205 وتظهر في قائمة الدخل وربح الرحلة.
- **الضرائب**: القيمة المضافة والدمغة ضمن السعر (2102/2106)، الخصم والإضافة يُحجز من مدفوعات الموردين (2105)، ما يخصمه العملاء (1108)، ضريبة الدخل/الزكاة تقديرية في قائمة الدخل.
- **المطبوعات**: وثيقة حجز للعميل (عمرة/داخلي) بالشروط والأقساط، سند قبض/صرف بنسختين والمبلغ بالحروف، فوتشر الفندق، فاتورة ضريبية.
